# Beginner Smart Contract Demo

## About
This project is a beginner-level Solidity smart contract demo.

The smart contract stores a number on the blockchain and allows the user
to update and read that number.

## Smart Contract Functions

### setNumber()
This function stores a number.

Example:
setNumber(25)

### getNumber()
This function reads the stored number.

Example:
getNumber() → 25

## Sample Test

1. Deploy the smart contract.
2. Call setNumber(25).
3. Call getNumber().
4. The result should be 25.
5. Call setNumber(100).
6. Call getNumber().
7. The result should be 100.
